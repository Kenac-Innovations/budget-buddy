## Headers checked on the production response

- Content-Security-Policy: self by default; self and fresh nonce for scripts; font self; connections self; objects none; base/form self; frame ancestors none. No script unsafe-inline or production unsafe-eval.
- Strict-Transport-Security: max-age=31536000; includeSubDomains (effective on HTTPS).
- X-Content-Type-Options: nosniff.
- Referrer-Policy: strict-origin-when-cross-origin; private `/r/*` routes use no-referrer.
- Permissions-Policy: microphone=(self), camera=(), geolocation=().
- X-Frame-Options: DENY.
- Session HTML uses private, no-store; X-Powered-By is absent.

## Short manual UI test script

1. Start demo mode on port 3206. Load `/` in light and dark modes; verify hydration, theme and no CSP errors. Inspect response headers and fresh nonces across reloads.
2. Load `/privacy` at 360px, then laptop width. Read every section, follow source links, and check no horizontal overflow in either theme.
3. Select Delete my plan, then Keep my plan: no deletion request. Confirm deletion against T3's authenticated route: show success, clear the device draft and preserve theme. Repeat with a failed request: show calm failure copy and retain the draft.
4. Follow the integrated advisor footer's How we handle data link. Return to your plan. Stop the server.
