# T7 · Advisor evals

Twelve synthetic Zimbabwean ICT scenarios now drive the advisor's NDJSON route with isolated cookie jars. Deterministic checks catch invented prices, unsupported evidence, unsolicited brands, voice violations and broken plan operations. A configurable simulated-user model and independent rubric judge support live release evaluation; demo runs use scripted users and leave quality scores unjudged.
