## Browser evidence and short manual script

1. Run the demo on port 3208 as described in release notes, with a fresh synthetic local Kenac view secret. Open a fresh context at 1440 × 960 or 360 × 800 in each theme. Greeting must precede contact form and issue exactly one resume GET returning 204.
2. Send section 6’s two messages. Observe plan before reply ends, source date and Spotted firewall. Accept both objectives, solar and firewall; dismiss SD-WAN with “Power comes first; review connectivity after opening.” Accept the three lines.
3. Ask solar cost: Unpriced. Enter USD 3,500/unit on solar: US$14,000 so far, two unpriced. Check mobile sheet opens/closes without overflow. Ask to wrap up; email checked, contact unchecked.
4. Save synthetic details without SMTP. Keep private return link; download XLSX. Choose one share, preview no allocation/contact, confirm. Protected Kenac view shows only that item. Open return link in a separate dark desktop browser; estimate and dismissal reason intact. Withdraw share.
5. Follow footer to privacy. Cancel deletion and verify plan persists; then confirm. Server resume becomes 204, original return link expires, device drafts vanish and theme persists. Stop server. For release, repeat with genuine Postgres, controlled SMTP, native Excel and physical phone/mobile data.

[Executable browser review](T8/browser-review.cjs) records synthetic data only. Review context chooses `?review=desktop-light`, `desktop-dark`, `phone-light` or `phone-dark`; the script creates isolated browser contexts. Its artifact root and test secret are local review configuration.
