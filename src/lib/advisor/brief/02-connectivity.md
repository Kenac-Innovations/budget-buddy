# Connectivity and redundancy (fibre, LTE, satellite)

Status: DRAFT, awaiting Kenac review
Review date: 2026-10-14 (draft preparation; no Kenac sign-off)
Next review: 2027-01-14, or sooner if source guidance changes

## What it is
Resilience combines appropriate access paths with working failover. Two links may still share power, a last-mile route or upstream infrastructure; validate independence instead of counting links.

## Who it fits in Zimbabwe
Planning judgement: investigate an alternate path for sites where connectivity interrupts a business outcome. Keep current links where availability meets the agreed target; choose fibre, mobile or satellite only after site-specific checks.

## When it is hype or premature, and prerequisites
Premature: assuming a second subscription guarantees uptime. Prerequisites: a coverage and capacity test, authorised local service, application latency tolerance, protected router power and an owner for failover tests.

## Common failures
Common failures to check: shared physical route, exhausted data allowance, inbound access constraints and failover that was never exercised. Include equipment, ongoing service and testing separately.

## Questions to ask
What happens when the primary path fails? Can essential applications run on the backup path?
